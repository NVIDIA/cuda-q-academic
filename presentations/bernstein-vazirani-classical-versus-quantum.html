Bernstein–Vazirani

A black box computes f(x) = s·x mod 2 for a hidden string s. Find s classically one query at a time, then watch one quantum query do it by interference.

Instructions
  1. Set the length n and the secret string s. Both tabs use the same black box.
  2. Classical: build an input x and query f(x). Every candidate string that would have answered differently is crossed out. Count how many queries it takes until one candidate remains.
  3. Quantum: click the three steps (superposition, oracle, interference) and watch the amplitude distribution. The matching line of math is highlighted below.

Keyboard: Tab moves between controls; the focused slider shows a green ring. ← → switch tabs and move within button rows. Enter or Space presses a button. Esc resets the current tab.

Neutral Atom Leakage and Loss Errors

Ten atoms in optical tweezers. Each atom has many energy levels, but only two of them are the qubit. Sweep an X gate across the array, one site at a time, and see which failures the readout catches and which it quietly scores as a success.

Instructions

Two levels are the qubit

  • Target state 1  |0⟩ = |F = 3, mF = 0⟩
  • Target state 2  |1⟩ = |F = 4, mF = 0⟩

This pair, the clock states, is the most stable in the atom, so the qubit is stored there. An X gate is a laser pulse tuned to flip the atom from |0⟩ to |1⟩.

The levels next door are not

F = 3 and F = 4 each contain a whole group of closely spaced levels, labeled by mF. Only mF = 0 belongs to the qubit; the diagram shows the four nearest neighbors, mF = ±1 in each group.

A stray photon or a slightly imperfect pulse can knock the atom sideways into one of them. That is leakage: the atom is still there, but it is no longer a 0 or a 1, so ordinary error correction has nothing to work with.

To read the qubits, you shine light on the array and see which atoms glow: those in F = 4 light up, those in F = 3 stay dark. That answers only one question — which group is the atom in? — and cannot tell which mF level it sits in. So a leaked atom in F = 4 is counted as a 1 and one in F = 3 as a 0, and the error goes unnoticed. Only atom loss gives itself away: an empty trap is obvious.

Run it

  1. Every atom starts in |0⟩. Nothing has been gated yet.
  2. Drag the sweep slider to move the X gate across the array, or press Step to advance one site at a time. Play runs the sweep on its own and can be paused at any point.
  3. After each site, the level diagram lights up the level the atom actually ended in and the verdict box explains what readout will make of it.
  4. Finish all ten sites and read the Results box. Five sites fail every shot: one leaks into each of the four mF = ±1 levels, and one loses its atom.

Keyboard: Tab between controls, Left/Right to move the slider or browse sites, Enter to activate, ESC for a new shot.

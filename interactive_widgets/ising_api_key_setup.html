QUANTUM TANGIBLE WORKSHOP

NVIDIA Ising Setup

Prepare an isolated Python environment and generate a personal NVIDIA API key for the workshop.

Learn more about the NVIDIA Ising models and QCalEval.

Set up a virtual environment

A virtual environment is a private Python installation inside your workshop folder. Packages installed there do not alter your system Python or Anaconda environment.

0 Create your workshop folder

Terminal / PowerShell
mkdir quantum_tangible_workshop
cd quantum_tangible_workshop
If you have Anaconda installedAnaconda may register its own Jupyter kernel. Complete the kernel-registration steps below so the notebook uses the workshop virtual environment.

1 Create and activate the environment

macOS / Linux
python3 -m venv .venv
source .venv/bin/activate
Windows PowerShell
python -m venv .venv
.venv\Scripts\Activate.ps1

Your prompt should now begin with (.venv).

2 Install the required packages

Terminal / PowerShell
pip install --upgrade openai jupyter ipykernel

3 Register the environment as a Jupyter kernel

Terminal / PowerShell
python -m ipykernel install --user --name=ising --display-name "Python (.venv ising)"

Launch Jupyter, then choose Kernel → Change Kernel → Python (.venv ising).

Terminal / PowerShell
jupyter notebook

4 Verify the active kernel

Notebook cell
import sys
print(sys.executable)
What you want to seeThe printed path contains .venv. If it shows /opt/anaconda3/bin/python, change the notebook kernel to Python (.venv ising).

Generate and configure your NVIDIA API key

Each student should use a personal key. Generate it before the workshop if possible.

1 Generate the key

  • Go to build.nvidia.com and sign up for a free NVIDIA Developer account.
  • Open Ising Calibration 1.5 31B.
  • Click Get API Key, then copy the key beginning with nvapi-.
Keep the key privateDo not paste it into a notebook cell, upload it with an assignment, or share it with another student.

2 Set the key and launch Jupyter

Run these commands from quantum_tangible_workshop in the same terminal window.

macOS / Linux
Terminal
source .venv/bin/activate
export NVIDIA_API_KEY="nvapi-xxxxxxxxxxxxxxxxxxxxxxxx"
jupyter notebook
Windows PowerShell
PowerShell
.venv\Scripts\Activate.ps1
$env:NVIDIA_API_KEY="nvapi-xxxxxxxxxxxxxxxxxxxxxxxx"
jupyter notebook

If activation is blocked, run Set-ExecutionPolicy -Scope CurrentUser RemoteSigned once, then retry.

Order mattersSet the key before launching Jupyter and use the same terminal window so the notebook inherits NVIDIA_API_KEY.

3 Verify the setup

In the workshop notebook, select Python (.venv ising) and run:

Notebook cell
import os, sys

assert ".venv" in sys.executable, "Select the Python (.venv ising) kernel."
assert "NVIDIA_API_KEY" in os.environ, "Restart Jupyter from the terminal where you set the key."
print("Environment and API key are ready.")
Setup completeYou are ready when the cell prints Environment and API key are ready.

Set Up NVIDIA Ising Calibration for Jupyter

An optional three-stage setup guide to prepare a Python environment, connect with a free NVIDIA API key, and download example calibration data for use with ising-calibration-1.5-31b.

Learn more about the NVIDIA Ising models and QCalEval.

Set up a virtual environment (do this first)

A virtual environment ("venv") is a private, self-contained copy of Python that lives in your project folder. Anything you install into it stays there — so the workshop packages never collide with your system Python or your Anaconda setup. Create it once, then work inside it.

0 Create your workshop folder

So everyone starts from the same place, create a folder named quantum_tangible_workshop and move into it. Run this wherever you keep your projects.

Terminal / PowerShell 
mkdir quantum_tangible_workshop
cd quantum_tangible_workshop
⚠ If you have Anaconda installed, read this Anaconda often auto-activates its base environment and registers its own Jupyter kernel. That kernel can hijack your notebook even when your venv is active in the terminal — which is why import openai fails with a package you "already installed." The kernel-registration step below is what prevents this.

1 Create & activate the venv

Run these from inside the quantum_tangible_workshop folder you just created.

macOS / Linux — Terminal 
python3 -m venv .venv
source .venv/bin/activate
Windows — PowerShell 
python -m venv .venv
.venv\Scripts\Activate.ps1

Your prompt now shows (.venv) at the start of the line. That's how you know the environment is active. Everything you install from here goes into .venv, not your global Python.

2 Install the workshop packages

With the venv active, install everything you need in one go:

Terminal / PowerShell 
pip install --upgrade openai jupyter ipykernel
  • openai — the client library that talks to the Ising API required
  • jupyter — runs your notebook
  • ipykernel — lets Jupyter use this venv as a kernel (next step)
  • pillow — only if you later need to shrink an oversized image (optional — add it only if you hit the image-size note)

3 Register the venv as a Jupyter kernel

This is the step that makes Jupyter actually use your venv instead of Anaconda's Python. Still inside the activated venv:

Terminal / PowerShell 
python -m ipykernel install --user --name=ising --display-name "Python (.venv ising)"

Now launch Jupyter and, in the notebook, choose that kernel via Kernel → Change Kernel → "Python (.venv ising)".

Terminal / PowerShell 
jupyter notebook

4 Verify you're in the right environment

In a notebook cell, run:

Notebook cell 
import sys
print(sys.executable)
✓ What you want to see A path that contains .venv (e.g. .../QBlox Workshop/.venv/bin/python). If instead you see something like /opt/anaconda3/bin/python, the notebook is still on the Anaconda kernel — go back to Kernel → Change Kernel and pick "Python (.venv ising)".

When you're done for the day, type deactivate to leave the venv. Next session, just re-run the activate line — you don't recreate anything.

Ready to continue when Your terminal prompt begins with (.venv), Jupyter uses the Python (.venv ising) kernel, and sys.executable points inside .venv.

Connect to NVIDIA Ising Calibration

Generate your personal API key, make it available to Jupyter, and confirm that the notebook can read it. The key-generation steps are the same on every operating system; only the terminal commands differ.

Prerequisite Complete the Environment tab first. The commands below assume that you are inside quantum_tangible_workshop and have already created .venv.

1 Generate your NVIDIA API key

Do this before the workshop if you can.

  • Go to build.nvidia.com and sign up for a free NVIDIA Developer account.
  • Open ising-calibration-1.5-31b.
  • Click Get API Key and copy the key. It begins with nvapi-.
Keep the key private Do not paste your key into a notebook cell, upload it with an assignment, or share it with another student. Store it in the terminal environment as shown below.

2 Activate the environment, set the key, and launch Jupyter

Choose your operating system. Run all three commands in the same terminal window.

macOS / Linux
Terminal 
source .venv/bin/activate
export NVIDIA_API_KEY="nvapi-xxxxxxxxxxxxxxxxxxxxxxxx"
jupyter notebook
Windows PowerShell
PowerShell 
.venv\Scripts\Activate.ps1
$env:NVIDIA_API_KEY="nvapi-xxxxxxxxxxxxxxxxxxxxxxxx"
jupyter notebook

If activation is blocked, run Set-ExecutionPolicy -Scope CurrentUser RemoteSigned once, then retry.

Order matters Set the key before launching Jupyter and use the same terminal window. A notebook opened from another terminal may not inherit NVIDIA_API_KEY.

3 Verify the notebook environment

Open the workshop notebook, select the Python (.venv ising) kernel, and run:

Notebook cell 
import os, sys

assert ".venv" in sys.executable, "Select the Python (.venv ising) kernel."
assert "NVIDIA_API_KEY" in os.environ, "Restart Jupyter from the terminal where you set the key."
print("Environment and API key are ready.")
Ready to continue when The verification cell prints Environment and API key are ready. Download the workshop plots next; you will connect the client and run the model in the workshop notebook.

Download calibration data

Choose plots to analyze in the workshop notebook. They are grouped by experiment type, and the numbered variants let you compare different plotting conventions, signal quality, and experimental outcomes.

How to save Click Download under one plot, or use Download all images (.zip) to retrieve the complete image set. Extract the archive so the calibration_images folder sits beside the workshop notebook. If you download an individual plot, save or move it into that folder.
Image format Ising accepts RGB PNG and JPEG images. PNG is recommended for plots because it preserves small text, thin curves, and sharp heatmap boundaries without compression artifacts.

Reference and troubleshooting

Understanding the two key settings

temperature = 0.2 — controls how random the output is (0 = focused/repeatable, higher = more varied). Low is right for calibration: the same plot should give a stable, factual read, not creative variation.

max_tokens = 8192 — the cap on response length. The workshop uses 8192 for both the single-plot zero-shot calls and the short two-image ICL exercise. Raise it only if a response is visibly cut off.

Rate limits & etiquette
  • 40 requests/minute and 1,000 credits per key. One analysis = one request, so you have lots of headroom.
  • Use your own key — don't share one key across laptops, or you'll all hit the limit at once.
  • If you see 429 Too Many Requests, wait a few seconds and retry.
Image too large? (400 / 413 error)

If the hosted API rejects a large inline image, downscale it while preserving readable labels and curves (requires pip install pillow):

Notebook cell 
from PIL import Image
import io, base64

img = Image.open("ramsey.png")
img.thumbnail((1024, 1024))       # plots stay readable
buf = io.BytesIO(); img.save(buf, format="PNG")
image_b64 = base64.b64encode(buf.getvalue()).decode()

Ising Calibration supports RGB PNG and JPEG/JPG. PNG is recommended for scientific plots.

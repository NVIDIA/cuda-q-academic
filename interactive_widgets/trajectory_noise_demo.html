Trajectory Noise Demo

Visualize a simple trajectory-based error model.

Instructions
  1. Set Error Probability P(error) with the slider (0–0.20). This is the probability of error on each qubit in the trajectory.
  2. For each of Qubit 1, 2, and 3, choose No Error (0) or Error (1) to fix the trajectory. The tree highlights the path that matches your choices.
  3. The tree shows all 2³ outcomes; each leaf shows the bit string (e.g. 111) and P(outcome), e.g. P(|111⟩) = probability of that outcome. Green = no-error path; red = path with at least one error.
  4. Press ESC to reset to default (P = 0.10, all qubits No Error).

Keyboard: Tab to move between slider and buttons. ESC — reset. Enter or Space — activate focused button. ←/→ to move between No Error / Error buttons. Arrow keys adjust the slider when it is focused.

Try it in CUDA-Q

Show the code

Try the same idea in CUDA-Q: three qubits, each hit by a bit-flip error with probability p. CUDA-Q's trajectory sampler picks out the paths through the widget's tree, gives each its probability p^k (1 − p)^(3 − k) for k errors, and shares the shots out between them.

Python
%pip install cudaq
import cudaq
from cudaq import ptsbe


@cudaq.kernel
def three_qubits(p: float):
    # all start in |0>: no error means 0, an error means 1
    # Code qubits 0, 1, 2 = the widget's Qubit 1, 2, 3.
    qubits = cudaq.qvector(3)
    for q in range(3):
        # flip qubit q with probability p
        cudaq.apply_noise(cudaq.XError, p, qubits[q])
    mz(qubits)


# bit-flip probability per qubit; change it and re-run
p = 0.1

# Keep the most likely error paths and report their shot counts.
result = ptsbe.sample(
    three_qubits,
    p,
    shots_count=10000,
    noise_model=cudaq.NoiseModel(),
    max_trajectories=8,  # 2 x 2 x 2 = 8 paths through the tree
    # most likely paths first
    sampling_strategy=ptsbe.OrderedSamplingStrategy(),
    return_execution_data=True,
)

for trajectory in result.ptsbe_execution_data.trajectories:
    print(
        f"path {trajectory.trajectory_id}: "
        f"probability {trajectory.probability:.3f}, "
        f"shots {trajectory.num_shots}"
    )
# 000 = no errors, three 1s = an error on every qubit
print(result)

Copy into a Jupyter or Colab code cell and run it. The first line installs the required packages.

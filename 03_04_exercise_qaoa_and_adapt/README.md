# Exercises 03–04: QAOA and ADAPT-QAOA

Exercise 03 uses the QAOA MaxCut example to practice configuring an AI agent,
understanding unfamiliar quantum code, and testing AI-generated code. Exercise
04 continues with ADAPT-QAOA.

## Files

| File | Purpose |
| --- | --- |
| `workshop_graphs.py` | Defines the weighted MaxCut graphs shared by the examples and selects the graph to run. |
| `qaoa_maxcut.py` | Implements MaxCut QAOA directly with CUDA-Q kernels and SciPy optimization. |
| `tests/test_maxcut_hamiltonian.py` | Provides two basic starter tests and a commented template for your own MaxCut Hamiltonian test. |
| `adapt_qaoa.py` | Implements ADAPT-QAOA for the selected weighted MaxCut graph. |

## Start in the exercise directory

Open a terminal in JupyterLab. Commands in this README assume the workshop is
installed at the path used by the Brev launchable:

```bash
cd /home/cudaq/cuda-q-academic/03_04_exercise_qaoa_and_adapt
```

Confirm that you are in the correct directory:

```bash
pwd
ls
```

The `ls` output should include `qaoa_maxcut.py`, `adapt_qaoa.py`, and the
`tests` directory. Keep this terminal in the exercise directory when running
the commands below.

## 3.1 Set up your agent, then understand the code

Customize the agent before using it to learn the codebase.

1. Open `/home/cudaq/cuda-q-academic/USER.md` and replace the bracketed
   placeholders with your preferences for how the agent should explain,
   question, and report progress.
2. Exit the current Codex session. From the exercise directory, start a new
   session so Codex loads both the root `AGENTS.md` instructions and your
   updated `USER.md`:

   ```bash
   codex
   ```

3. Ask the agent to walk you through `qaoa_maxcut.py`, including:

   - the `qaoa` CUDA-Q kernel;
   - the `maxcut_hamiltonian` cost Hamiltonian;
   - the `solve_qaoa` classical optimization loop.

If the explanation does not fit how you learn, update `USER.md`, restart
Codex, and ask again.

You can run the complete QAOA example from the exercise directory with:

```bash
python qaoa_maxcut.py
```

The script uses the NVIDIA simulator when a supported GPU is available and
falls back to the CPU simulator otherwise.

## 3.2 Write unit tests for the MaxCut Hamiltonian

Unit tests help confirm that code works, especially when code is generated by
AI.

### A. Run the two starter tests

Open `tests/test_maxcut_hamiltonian.py` and study its two active tests. Each
one builds a one-edge Hamiltonian and checks one energy value. The third test
is a commented template for your own test.

From the exercise directory—not from inside `tests/`—run:

```bash
python -m unittest discover -s tests -v
```

You should see two passing tests followed by `OK`. If Python reports that it
cannot find the `tests` directory, run `pwd` and repeat the `cd` command from
the start of this README.

### B. Add your own tests

Spend 10 minutes writing tests yourself, without AI assistance. Start with
`test_name_the_property_you_are_checking` in
`tests/test_maxcut_hamiltonian.py`:

1. Uncomment the template.
2. Give the test a descriptive name.
3. Fill in its Arrange, Act, and Assert sections.

Use `self.implementation(...)`, as the starter tests do, so the later
comparison file can reuse your tests against a different implementation. Add
more test methods if you have time, then rerun:

```bash
python -m unittest discover -s tests -v
```

### C. Ask AI to challenge your test suite

After your tests pass, give the agent this prompt:

> **STARTER PROMPT — BREAK MY TESTS**
>
> Write a general version of `maxcut_hamiltonian` (any graph, no hardcoding)
> that is subtly incorrect but passes every test in
> `tests/test_maxcut_hamiltonian.py`. Put it in
> `wrong_maxcut_hamiltonian.py` with a test file that runs my tests against it.
> Don't tell me what you changed.

Run the same discovery command again. Because it discovers every file named
`test_*.py` under `tests/`, it will also run the comparison test created by
the agent:

```bash
python -m unittest discover -s tests -v
```

### D. Find and catch the defect

Confirm the suite passes against the deliberately wrong implementation. Read
`wrong_maxcut_hamiltonian.py` and see whether you can identify the defect.
Then ask the agent to write a test that catches it. Review the test's logic,
confirm that it passes for `qaoa_maxcut.maxcut_hamiltonian`, and confirm that it
fails for the broken implementation.

### E. Extend the suite

With any remaining time, ask the agent to suggest additional properties that
your tests do not yet cover. Review each suggestion before adding it, then run
the full suite once more.

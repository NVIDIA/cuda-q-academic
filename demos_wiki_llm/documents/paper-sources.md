# Paper Sources

For arXiv papers, use the `abs` URL as the canonical source URL, but prefer the
arXiv HTML version for ingestion when available. Fall back to PDF only when the
HTML is unavailable or misses figures, tables, equations, or page-specific
evidence needed for the wiki entry.

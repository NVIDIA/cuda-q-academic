Instructions

What this panel establishes

Each dot is a feature vector

Its coordinates are the values in xi. The known label yi is stored separately—it is not another coordinate.

dᵢ = yᵢ(w·xᵢ+b)/‖w‖   and   m = minᵢ dᵢ

Here dᵢ is the signed geometric distance and m is the half-margin; the full margin width is 2m.

The hard-margin optimization

Fix the score scale so the nearest signed score is 1, then minimize the weight norm.

minimize ½‖w‖²   subject to   yᵢ(w·xᵢ+b) ≥ 1

From a wide boundary to the objective

1 · Fix score units Set the nearest correctly classified examples to signed score 1.
2 · Measure width On that common scale, a wider margin has a smaller ‖w‖.
3 · Optimize Minimize ½‖w‖² while keeping every signed score at least 1.

Hard margin, soft margin, and feature scaling

This explorer uses separable hard-margin geometry. Soft-margin SVMs allow violations through slack and penalize them with C, so their minimum signed score need not be 1. Feature scaling is different again: it changes x and can change the fitted model. Later notebook examples use soft-margin C=1.

In this exercise, you will be using the [Ising Calibration agent playground](https://build.nvidia.com/nvidia/ising-calibration-1-35b-a3b/playground).  


1. **Open the Ising Calibration playground**. Navigate to the Ising Calibration agent playground.
2. **Examine the calibration results**. Download `calibration_example.png` from this directory and review it to familiarize yourself with the experiment output before querying the agent. 
3.  **Query the agent with your data**. Attach `calibration_example.png` and prompt the agent to explain the results of the calibration experiment.
4. **Simulate a calibration test (optional)**. Use the [CUDA-Q dynamics](https://nvidia.github.io/cuda-quantum/latest/using/examples/dynamics_examples.html) API to generate a plot simulating one of several calibration tests for superconducting transmon qubits. Upload the plot to the playground and ask the agent for the experimental conclusion and significance.

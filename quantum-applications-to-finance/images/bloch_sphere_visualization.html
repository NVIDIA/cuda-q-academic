Bloch Sphere Visualization

Visualize the circuit's output on the Bloch Sphere by entering rotation angles for each gate.

Instructions
  1. Choose Radians or Degrees, then type rotation angles for Rx, Ry, and Rz into the input fields (0 – 2π radians, or 0 – 360°). Use Tab to move between fields.
  2. Watch the circuit diagram and the Bloch sphere update in real time as you type.
  3. Choose Play to start at |0⟩ and watch Rx, Ry, then Rz in order. Choose Pause to stop at an intermediate point, or Step to apply one complete rotation at a time. The current gate has a white outline.
  4. Reset to |0⟩ clears all three angles. Changing an angle shows the complete circuit's output again. Rotation order matters: try swapping the ry and rz lines in the CUDA-Q example below.
  5. Bloch sphere: Click or Tab to focus the sphere window; then drag to rotate the view, or use Arrow keys to rotate. A green outline shows when the sphere has keyboard focus.

Keyboard: Tab to move between inputs and the Bloch sphere. Arrow keys rotate the sphere when it is focused; Enter/Space activate buttons.

Try it in CUDA-Q

Show the code

Try the same idea in CUDA-Q: start in |0⟩, rotate with rx, ry, and rz, then plot the result. Change the angles to move the state anywhere on the sphere.

Python
%pip install cudaq qutip matplotlib
import cudaq
import numpy as np


@cudaq.kernel
def rotations(theta_x: float, theta_y: float, theta_z: float):
    qubit = cudaq.qubit()  # starts in |0>
    rx(theta_x, qubit)
    ry(theta_y, qubit)
    rz(theta_z, qubit)


# Rotation angles in radians (π/2 = 90°); try any values
theta_x, theta_y, theta_z = np.pi / 2, np.pi / 4, np.pi / 3

print(cudaq.draw(rotations, theta_x, theta_y, theta_z))
state = cudaq.get_state(rotations, theta_x, theta_y, theta_z)
cudaq.show(cudaq.add_to_bloch_sphere(state))

Copy into a Jupyter or Colab code cell and run it. The first line installs the required packages.

Things to try: Start with all angles zero, then set theta_y = np.pi / 2 and vary theta_z. How does the arrow move? Swap the ry and rz lines in the kernel: does applying the same rotations in a different order change the final state?

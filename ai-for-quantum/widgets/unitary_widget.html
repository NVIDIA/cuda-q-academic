Quantum Unitary Matching

Match the target unitary by building a circuit so that your vectors (translucent) align with the target vectors (solid) on the Bloch sphere for |0⟩, |+⟩, and |+i⟩.

Instructions
  1. Goal: On the single Bloch sphere, three solid arrows show where the target unitary sends |0⟩ (green), |+⟩ (cyan), and |+i⟩ (orange). Three lighter/translucent arrows show where your circuit sends the same states. Match your unitary to the target by applying gates until the translucent arrows align with the solid ones.
  2. Apply gates (X, Y, Z, H, S, T) so each of your three vectors coincides with its target. Use Reset Circuit or Undo as needed. Your circuit starts as the identity (your arrows begin at the poles).
  3. Maximize the Unitary Fidelity (1.0 = perfect match). When all three pairs of arrows overlap, fidelity is 1.
  4. Drag the sphere to rotate the view; when focused, use arrow keys to rotate.

Keyboard: ESC to reset. Tab to move between gates and the Bloch sphere. Enter/Space to activate buttons. When the Bloch sphere is focused, ←→↑↓ rotate the view.

Try it in CUDA-Q

Show the code

Try the same idea in CUDA-Q: write your circuit's gates in a kernel, as you would click them in the widget, and score it against the widget's target with the widget's fidelity, |Tr(U_target† U) / 2|². Then see how CUDA-Q's cudaq.synth.gridsynth compiles a rotation into H, S and T gates, and why accuracy costs gates.

Python
%pip install cudaq
import cudaq
import numpy as np
from cudaq import synth

# The widget's target unitary (its columns made orthonormal)
Q, R = np.linalg.qr(
    np.array([[0.567 - 0.234j, -0.345 + 0.678j], [0.789 + 0.123j, 0.456 - 0.567j]])
)
target = Q * (np.diag(R) / abs(np.diag(R)))


@cudaq.kernel
def my_circuit(start_in_one: bool):
    q = cudaq.qubit()
    if start_in_one:
        # run from |1> as well as |0> to get both columns of the unitary
        x(q)
    # Your gates, in order: edit these lines like clicking gates in the widget (x, y, z,
    # h, s, t)
    h(q)
    t(q)
    h(q)


# Run both basis inputs to recover the circuit unitary column by column.
U = np.column_stack([np.array(cudaq.get_state(my_circuit, s)) for s in (False, True)])
print("Unitary fidelity:", abs(np.trace(target.conj().T @ U) / 2) ** 2)

# Compile Rz(theta) into H, S and T; tighter tolerance costs more T gates.
theta = 0.6
for tolerance in (1e-1, 1e-2, 1e-4, 1e-8):
    sequence = synth.gridsynth(theta, tolerance, seed=1)
    print(
        f"tolerance {tolerance:g}: {sequence.t_count:3d} T gates, "
        f"error {synth.rz_error(theta, sequence):.1e}, "
        f"{str(sequence)[:20]}..."
    )
